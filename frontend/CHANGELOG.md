# Web Application Changelog

All notable changes to the SherlskyyCommand web application are documented here.

## [0.3.0] - 2026-11-15

### Added

- A redesigned web command center with a refined workspace sidebar, elevated dashboard surfaces, and responsive navigation.
- Live workspace project metrics, project search, clear loading/empty/error states, and account status panels.
- A per-user “What’s new” dialog that announces unseen web application releases.

### Changed

- Project cards, actions, and account details now use a more focused, professional visual hierarchy.
- The displayed web application version is sourced from the repository release version.
